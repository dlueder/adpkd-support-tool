# PCKD/ADPKD Support Tool

In medical research of PCKD (german ADPKD) it is useful to mark and calculate the area and volume of harmful cells. With ongoing development of sophisticated machine learning algortihms for object detection and instance segmentation this tool makes it easier and faster to evaluate cell images
